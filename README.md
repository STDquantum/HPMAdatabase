# HPMA 图鉴

`clothes.json` 是图鉴数据的合并源，`index.html` 由它生成并显示所有已合并条目的并集。卡牌数据从 `E:\download\hpma\HPMA\卡牌网页整理\卡牌信息.json` 读取，不解析卡牌 HTML。

## 手动采集藏宝阁商品

网站有自动化防护，采集过程由人操作浏览器，不使用自动化登录或自动点击脚本。

1. 在浏览器中打开藏宝阁商品列表，手动登录账号，并按“价格”降序排列。
2. 按价格顺序逐个打开商品详情，点击详情页中的“装饰”标签。
3. 在开发者工具中找到该页的 `div.content`，复制整个元素（包括外层 `<div class="content">`），保存到本目录的 `test1.html`。每个商品都覆盖这个文件，不要追加上一个商品的内容。
4. 在本目录运行：

   ```powershell
   node get_cangbaoge.js
   ```

5. 确认命令完成后，再处理下一个商品。

每次运行会解析当前 `test1.html`，把新条目合并进 `clothes.json`，下载新增图片，并重建 `index.html`。JSON 中已有的记录会保留；同类别、同名称但图片 URL 不同的条目会分别保存。重复处理同一商品不会增加重复记录。首页因此持续显示所有已合并数据的并集。

## 其他

- 请从 `HPMAdatabase` 目录运行命令。
- 运行前必须将当前商品的内容保存为 `test1.html`；脚本固定读取这个文件。
- 装饰图片保存在 `clothes/` 的分类目录；卡牌静态素材复制到 `clothes/cards/background/`。首页使用本地图片。
